# AAAI SUT-invariant measurement (IRT)

AAAI 메인 트랙 논문 "AV 적대 평가의 SUT-불변 측정 — IRT 기반 공통 척도" 연구 정리 저장소.

연구 사이트는 root `index.html`이 `research/index.html`로 자동 redirect한다. 주요 페이지는 다음과 같다.

- **연구 개요** — `research/index.html`
- **연구 계획 (Plan)** — `research/plan.html`
- **방법 형식화 (Method)** — `research/method.html`
- **수행 로드맵 (Roadmap)** — `research/roadmap.html`
- **결정 로그 (Decisions)** — `research/decisions.html` (D-01 ~ D-10 + 잔여 위험 R-A ~ R-G)
- **D-study 결과** — `research/d-study.html`
- **Literature Review** — `research/review/index.html` (5 섹션 약 30 정독 카드)
- **질의 로그** — `research/questions-log.html`

분석 코드는 `analysis/` 아래(A1 식별가능성 점검, A2 추정 절차, A3 공변량, A4 라벨러, D-study 격자 sweep)에 있고, 협업 도구·시뮬레이터 운용 결정은 `CLAUDE.md`·`HANDOFF.md`·`.claude/agents/research-reviewer.md`에 적혀 있다.

외부 라이브러리(SafeBench, FREA)·외부 논문 PDF·세션 transcripts·메모리 사본은 보안·저작권 이유로 저장소에 포함하지 않는다(`.gitignore` 참조).

본 저장소는 private이며 저자 동의 없는 무단 배포·인용을 금한다.

질의 로그 · PDF 요청

두 도구를 목적별로 분리해서 씁니다. leapspace는 ScienceDirect 코퍼스 전반의 광역 서베이("이런 주장을 하는 논문들을 찾아 정리해줘"). 특정 논문의 표·수치·인용문은 정확도를 위해 PDF를 받아 직접 분석합니다.

협업 루프 · 도구 역할

도구별 역할 (교정됨)

leapspace (광역 조사): 특정 논문 한 편을 파고드는 용도가 아니라, 분야 전반에서 "X를 주장/관찰/제안하는 논문들"을 폭넓게 찾아 목록·요약을 받는 용도. 아래 L1~L8이 이 형식입니다.

PDF 직접 분석 (정밀): 특정 논문의 정확한 수치·표·인용문(예: LD-Scene Table 4의 41→63%)이 필요하면, 그 논문을 ../pdfs/에 넣어주시면 제가 전문을 정독해 문헌 검토에 verbatim으로 정리합니다. 아래 PDF 트래커 참조.

사이클

① 광역 질문(나) → ② leapspace 수집(당신) → ③ 후보 논문 선별·검토(나) → 특정 논문 정밀 필요 시 ④ PDF 요청(나) → 경로에 PDF(당신) → ⑤ 전문 정독 → 문헌 검토 저장(나) → 부족하면 ①로. arXiv/오픈액세스(예: Waymo·Nature Comm·ICLR workshop)는 제가 직접 받아오니 PDF 불필요.
